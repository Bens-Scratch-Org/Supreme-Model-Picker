A Copilot pricing thought-experiment

If GitHub dropped PRU billing for tokens, who actually wins?

GitHub Copilot meters most models in premium request units — fixed-price chats with a per-model multiplier. Direct API providers meter in tokens. These two systems disagree sharply about what the same conversation should cost. This is a walkthrough of that disagreement, built on the data in analysis/model-comparison.md.

1The question

On a paid Copilot plan today, a chat with GPT-4o costs $0, a chat with Claude Opus 4.7 costs $0.30, and the actual provider token cost of those two conversations is roughly $0.03 and $0.07 respectively. PRU and tokens disagree by an order of magnitude in opposite directions. So — what would actually move if GitHub flipped the switch?

Three things change on day one. Included models stop being free. Ultra-premium gets ~4× cheaper. And what drives your bill stops being which model and starts being how many tokens you sent it.

2The world we live in: PRU multipliers

Every Copilot model has a multiplier — the number of premium requests one chat consumes. Five tiers, ranging from 0× (free) to 7.5× (ultra-premium). A 1× chat costs $0.04 in overage; a 7.5× chat costs $0.30. Hover any bar for details.

Copilot premium-request multiplier by model
Higher = more PRU consumed per chat. The 0× tier is free on paid plans.

3The hidden subsidy

Subtracting the actual provider-token cost of a typical 4K-in / 2K-out chat from the PRU charge for that same chat reveals who is over- and under-charged. Bars to the right overpay through PRU (subsidizing other users); bars to the left get a discount.

PRU price minus actual token cost · per chat
Positive (right) = PRU overcharges · Negative (left) = PRU undercharges · Free models pay nothing in PRU but tokens would meter
The 7.5× tier funds the free tier. Claude Opus 4.7 and GPT-5.5 are priced at 3.8–4.3× their actual token cost, while GPT-5 mini, GPT-4.1 and GPT-4o are offered at a 100% discount. Token-based pricing would unwind that subsidy in both directions.

6Who wins, who loses

Mapping the seven personas from the source analysis onto the math: a casual user barely notices, a power user saves tens of dollars a month, and an agent-heavy team gets a nasty surprise.

7The verdict

The PRU model is a deliberate cross-subsidy: ultra-premium overcharges fund the zero-cost included tier. Switching to tokens would be a transfer of value from casual users to power users, and from chat-style users to anyone aggressively caching long system prompts.

✅ Stop rationing Opus

Under tokens, Opus 4.6 / 4.7 drops to ~$0.07/chat — cheaper per SWE-bench point than every model except budget-tier.

✅ Gemini 3.1 Pro becomes the default

$0.032/chat undercuts Sonnet's $0.042 with similar SWE-bench scores. The new mid-tier sweet spot.

⚠️ Free tier disappears

GPT-5 mini, GPT-4.1, GPT-4o all start metering at $0.005–$0.030/chat. The biggest casual-user shock.

⚠️ Agentic workflows get expensive

PRU's "tool calls don't count" rule disappears. A 50K-token agent run on Opus 4.7 = $0.65; same run on Haiku = $0.13.

🏷️ GPT-5.5 loses its rationale

12.5% more expensive than Opus 4.7 token-for-token, with weaker SWE-bench evidence. Tied at 7.5× under PRU; strictly worse under tokens.

💾 Caching becomes the new lever

Anthropic / Gemini cached-input is 90% off. A stable 10K-token system prompt becomes effectively free. PRU never rewarded this.

Bottom line. The PRU system is likely a deliberate strategic choice — subsidize the premium tier from ultra-premium overcharges while keeping the base experience free to maximize adoption. A token switch would benefit power users dramatically but would remove the zero-cost on-ramp that makes Copilot's baseline so attractive.
