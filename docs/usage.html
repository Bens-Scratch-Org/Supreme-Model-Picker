Drop your Copilot Usage Data export to see what it actually says.

GitHub's enterprise Copilot usage export is a per-user, per-day NDJSON stream of every interaction, code suggestion, acceptance, language, feature, model, IDE and CLI token burn. Drop your .ndjson file below and this page will parse it entirely in your browser — nothing is uploaded — and turn it into a summary you can scroll through, screenshot, or print.
